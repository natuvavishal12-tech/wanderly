# Wanderly 🌍

**Your AI-powered travel companion**

Plan perfect trips, discover destinations, book flights & hotels, and share stories — all in one beautiful platform.

## Features (MVP + more coming)

- ✨ Beautiful homepage & destination discovery
- 🤖 AI Trip Planner
- 📅 Day-wise itinerary builder
- ❤️ Wishlist & saved trips
- 👤 User accounts (Supabase Auth)
- 🗺️ Interactive maps (coming)
- 📝 Reviews & community stories
- 💳 Booking flow (Razorpay)

## Tech Stack

- **Frontend**: Next.js 15 (App Router) + TypeScript + Tailwind CSS
- **Backend / Auth / DB**: Supabase
- **Hosting**: Vercel

## Getting Started

1. Clone the repo
2. Copy `.env.example` → `.env.local` and fill in your Supabase keys
3. `npm install`
4. `npm run dev`
